# Documentation

Documents an application needs in its own repository:

- [delivery/](delivery/README.md): the delivery plan, structured as Outcome, Epics, Features, Stories and Tasks, with one overall plan and a file for each piece of work
- [runbook.md](runbook.md): the one-off setup steps for the identity provider registrations, the GitHub Environments and the AWS account bootstrap

The developer setup guide is part of the AI application standard and is not copied here.
